# Portrait

The headshot at 4:5 on a gold hairline frame offset 14px down and to the right.

## When to use
Once, beside the name in the intro. It is the only photograph in the system.

## Markup
`figure.wm-portrait > img` (720 × 900 source, `assets/Images/headshot.jpg`).

## The consumer provides
Room for the 14px frame offset on the right and below. `portrait-max` (320px) wide beside the text; about 240px, above the name, below `bp-stack`.

## Don't
Round, circle-crop or filter the photo, or use another person's image in this frame.
