# Credential List

Three labeled columns of short items, each a name in `text` with its detail in `muted` beneath, separated by hairline rules.

## When to use
For education, certifications and awards: short facts that need no sentence.

## Markup
`.wm-creds > div > h3.wm-creds__label.eyebrow + ul > li (name + small)`

## The consumer provides
Three groups of two to four items each; the columns stack below `bp-grid`.
