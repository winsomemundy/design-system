# Contact Channel

A full-width `panel` link with an uppercase `gold` label on the left and the address on the right.

## When to use
In the contact section, one per channel. Show the address itself as text so it can be read and copied even if the link does nothing.

## Markup
`.wm-channels > a.wm-channel > span.wm-channel__label.topic + strong.wm-channel__value`

## The consumer provides
Public channels only: email and LinkedIn. Never a phone number or street address on a public page.

## Phones
Below `bp-phone` the label stacks above a left-aligned value.
