# Script Line

A single featured statement in Allura, in `gold`, with an optional plain note beneath in `muted`.

## When to use
At most once per section, for a line meant to be felt rather than scanned: the teaching honor, the contact sign-off. `script-lg` for a featured statement, `script-md` for a sign-off.

## Markup
`p.wm-script.script-lg` (or `.script-md`), optional `small.wm-script__note`.

## Don't
Set more than two lines in script, use it for headings or labels, or color it anything but `gold`.
