# Win List

A two-column list of accomplishments, each opened by a violet diamond and separated by hairline rules.

## When to use
For a set of achievements or benefits where each item is a sentence. Bold (`strong`, `text` color) the few words that carry the item.

## Markup
`ul.wm-wins > li` with one `strong` per item.

## The consumer provides
An even number of items when possible; the list goes to one column below `bp-nav`.

## Don't
Use it for navigation or for short one-word items; use the Credential List for those.
