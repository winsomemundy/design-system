# Teaching Card

A `panel` card for a teaching post: institution and dates on one line, the role in `text`, then a `muted` description.

## When to use
For teaching, consulting or other non-timeline roles, stacked in a single column beside a Script Line.

## Markup
`article.wm-card > .wm-card__head (h3.wm-card__title.heading-sm + span.wm-card__date.date) + p.wm-card__role + p.wm-card__text`

## The consumer provides
The institution, the year range, the role with city, and one or two sentences.
