# Values Strip

The six values from the brand banner in one row: a gold diamond, the value's name in uppercase and one short first-person line.

## When to use
The home page stopped using it in v1.6.0: the principles in "How I build products" now carry the values, with proof. It stays in the system for pages that want the values in brief. When used, it goes directly under the Hero. The six values are fixed and always appear in this order: Integrity, Excellence, People centered, Value driven, Adaptive, Data informed.

## Markup
`section.wm-values > ul.wm-wrap.wm-values__grid > li > h2.wm-values__name + p.wm-values__text`

## Layout
Six across from 1080px, three across below that, two across at 560px and below. Hairline dividers sit between items in a row, never at a row's start. Every name stays on one line at every width; "People centered" is the longest and sets the type size (0.74rem, 0.08em spacing).

## The consumer provides
The values' own words, one sentence each, in the first person:
- Integrity: "I do the right thing. Always."
- Excellence: "I strive for quality in everything I do."
- People centered: "I listen, collaborate and empower."
- Value driven: "I focus on outcomes that matter."
- Adaptive: "I embrace change and learn continuously."
- Data informed: "I make decisions with insight and clarity."

## Don't
Add icons (the diamond is the marker), reorder the values, or let a name wrap; shorten the spacing instead.
